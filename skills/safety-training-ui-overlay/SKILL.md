# Safety Training UI Overlay

## 추가 입력

- 교육 대상 연령
- 국가·지역
- 적용 법령·기관 지침의 출처와 기준일
- 실제 행동과 시뮬레이션 단순화의 차이
- 사용 장소와 감독자 유무
- 키오스크·VR·센서·주변기기
- 교육 시간과 반복 여부
- 음성·자막·다국어
- 개인정보 저장 여부
- 비상 중단·직원 호출 방식

## 사실 검증 게이트

다음은 모델의 상식으로 확정하지 않는다.

- 화재·대피·소화 행동 순서
- 응급처치와 CPR 절차
- 전기·교통·산업안전 행동
- 긴급전화 번호
- 국가·지자체·기관 명칭
- 어린이에게 허용·금지되는 행동

각 항목에 `출처, 관할 국가·기관, 발표·개정일, 적용 연령, 콘텐츠 반영일`을 기록한다.

## 필수 산출물

1. 교육 목표와 현실 행동 규칙
2. 지침 출처·버전 표
3. 정답·오답·부분 정답 피드백
4. 위험 행동의 표현 제한
5. 연령별 문장·아이콘·조작 기준
6. 키오스크 세션·초기화·오류 흐름
7. VR 멀미·시선·입력 기준
8. 현지화 검수표
9. 실제 환경 테스트 시나리오

## 어린이 기준

- 단계당 핵심 행동 하나
- 짧은 문장과 익숙한 단어
- 아이콘과 텍스트의 중복 신호
- 충분히 큰 조작 영역
- 실수 후 쉬운 되돌리기
- 과도한 공포·벌점·시간 압박 제한
- 보호자·교사·운영자용 도움 경로 분리

## 키오스크 기준

- 실제 거리와 조명에서 읽히는 크기
- 세션 시작·중단·시간 초과·초기화
- 이전 사용자 개인정보 자동 삭제
- 센서·인터넷·주변기기 오류와 재시도
- 직원 호출 또는 운영자 모드
- 화면 가장자리·기기 프레임의 터치 오차
- 장갑·휠체어·고령자·어린이 접근

## VR·360 기준

- 작은 글자와 얇은 선 제한
- gaze·ray·controller·hand tracking 입력 명시
- 색 외에 외곽선·크기·음향 등 선택 신호 제공
- 뒤쪽 목표의 방향 안내와 재호출
- 카메라 강제 회전·급격한 이동·고정 오버레이 제한
- 자막 위치·크기·대비 조절
- 시간 제한 완화와 재중앙화

## 교육 피드백 구조

```text
선택 결과:
정답·부분 정답·오답:
왜 그런가:
현실에서는 무엇을 해야 하는가:
다음 단계:
다시 확인할 자료:
```

점수만 보여주지 않는다. 오답 행동을 화려하게 반복 연출해 따라 하기 쉬운 시범으로 만들지 않는다.

## 현지화 검수

- 번역 정확도
- 읽기 수준
- 음성·발음
- 긴급번호
- 기관명
- 법령·지침
- 표지판·상징
- 날짜·숫자·단위
- 문화적 행동
- 화면 길이와 줄바꿈

## 검수 질문

- 학습자가 3초 안에 현재 해야 할 행동을 알 수 있는가
- 오답 연출이 위험 행동의 시범이 되지 않는가
- 점수보다 올바른 현실 행동과 이유가 강조되는가
- 국가·연령별 행동 지침이 출처와 기준일로 관리되는가
- 번역 외에 긴급번호, 기관명, 표지판, 음성, 문화가 현지화됐는가
- 키오스크가 이전 사용자의 데이터를 남기지 않는가
- 센서·인터넷·장비 실패 시 복구와 직원 호출이 가능한가
- 자막·음성·색상·아이콘이 서로 대체 가능한가
- 시간 제한을 연장·반복할 수 있는가
- VR 강제 회전·시야 고정·작은 글자가 없는가

## 금지

- 법령과 행동 지침을 모델의 상식으로 확정
- 한국 규칙을 다른 국가에 그대로 적용
- 공포·실패 연출을 학습 효과의 근거로 사용
- 어린이에게 복잡한 수치·메뉴·정밀 조작 요구
- 실제 비상 행동보다 게임 보상과 점수 경쟁 강조
- 장비 오류를 사용자 실수처럼 표시
